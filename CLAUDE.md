# myfamily

Single-file family expense tracker (`index.html` + `style.css`, plain JS, no build step). Deployed on Netlify, auto-deploys from GitHub `main`.

## Git workflow

- After making any code change in this repo, commit and push to `origin/main` automatically — do not ask for confirmation first. The user has pre-authorized this for this repo.
- Still use clear, descriptive commit messages per change.
- This auto-push authorization is scoped to this repo only.

# 我が家の家計簿 (My Family Expense Tracker)

A simple, single-file household expense tracker. No server, no build step — just a static `index.html` that stores data in the browser's `localStorage`.

## Usage

Open `index.html` in a browser, or serve it as a static site (see Deployment below).

- Add expenses by category (baby costs, rent, utilities, food, personal, or your own custom categories)
- Browse totals month by month
- Export/Import your data as a JSON file for backup

## Deployment

This is a static site — deployable as-is to Netlify, GitHub Pages, or any static host.
